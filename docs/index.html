공공 API 상태판

인증키 없이, 한국 공공데이터 API(공공데이터포털·NEIS·DART·KOSIS 등)가 응답하는지, 그리고 이 측정 위치(해외 클라우드)에서 닿는지 잽니다.

불러오는 중…

지금은 해외 클라우드(GitHub Actions)에서 잽니다. '이 위치에서 닿은 적 없음'은 기관 장애가 아니라 해외 접속 제한일 수 있습니다.

현재 상태

읽는 법

응답함
정해 둔 응답이 왔습니다.
일시 실패
이번 측정에서만 실패했습니다. 두 번 연속 실패해야 '응답 없음'으로 봅니다.
응답 없음
두 번 연속 연결 실패, 시간 초과(15초), 또는 서버 오류(5xx)입니다.
형식 변경
응답은 왔지만 정해 둔 형식과 다릅니다. 점검 페이지나 API 개편일 수 있습니다.
이 위치에서 닿은 적 없음
해외 측정 위치의 7일 이력 전체에서 한 번도 서버에 연결되지 않은 API입니다(연결 실패·시간 초과만). 원인은 확인하지 못했습니다(해외 접속 제한 등). 한 번이라도 닿았던 API가 실패하면 그대로 '응답 없음'으로 보입니다.
접근 거부
401·403·429 같은 거부 응답입니다. 방화벽이나 호출 제한일 수 있습니다.
측정 중단
그 위치의 마지막 측정이 평소 측정 간격의 3배(최소 90분)보다 오래됐습니다. 보이는 상태는 현재가 아닙니다.
폐기됨
공공데이터포털이 "서비스가 없거나 폐기됨"이라고 답했습니다.
  • L2는 키 없이 불러 게이트웨이(입구)가 정해진 오류로 답하는지만 봅니다. 기관 서버가 실제 데이터를 주는지는 알 수 없습니다.
  • L4는 기관이 공개한 샘플 호출로 실제 데이터와 필드 구조까지 봅니다. 필드 구조가 바뀌면 '구조 변경'을 표시합니다.
  • 30분 간격으로 예약하지만, GitHub 예약 실행은 크게 밀려 실제 간격은 몇 시간일 수 있습니다(2026-10-14~18 중앙값 약 3.5시간). 실시간 장애 알림 용도로는 맞지 않습니다.
  • 측정 위치마다 결과가 다릅니다. 일부 기관은 한국 밖 IP에서 오는 접속을 받지 않는 것으로 보입니다. 해외 클라우드에서 '응답 없음'이면 기관 장애가 아니라 해외 접속 제한일 수 있습니다.
  • 측정할 때마다 한국 공공기관과 무관한 주소(구글 정적 파일) 하나로 측정하는 쪽 회선을 먼저 확인합니다. 이것이 실패한 회차는 '측정 무효'로 응답률 계산에서 뺍니다.

이 페이지는 비공식 측정 결과입니다. 공식 장애·점검 안내는 각 기관과 공공데이터포털 공지를 확인하세요.
